## 🧠 Overview

**SAMBHAV 3.0** is the official techfest platform for DY Patil College of Engineering (DYPCOE), Akurdi. The website serves as the central hub for event information, registrations, team leaderboards, and announcements — engineered to handle high traffic during the event.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎪 **Events Showcase** | Browse all techfest events with categories and details |
| 🏆 **Leaderboards** | Real-time points tracking for CSE, MECH, and other depts |
| 📍 **Navigation** | Multi-page routing with smooth transitions |
| 🔧 **Mind Matrix** | Special event section with poster and registration |
| 📢 **Announcements** | Live updates and event schedule |
| 📱 **Responsive Design** | Optimized for mobile, tablet, and desktop |

## 🛠️ Tech Stack

| Layer | Technology |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/JSR2406/SAMBHAV3.0.git
cd SAMBHAV3.0

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
